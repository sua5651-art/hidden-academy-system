# 구글 시트에 기록 쌓기 — 설치 안내

> 용어 풀이
> · **Apps Script** — 구글이 무료로 주는 작은 서버. 구글 시트 안에 코드를 넣어 돌립니다.
> · **웹앱 주소** — 그 서버를 바깥에서 부를 수 있는 인터넷 주소. 앱이 이 주소로 기록을 보냅니다.
> · **배포** — 코드를 인터넷에서 쓸 수 있게 켜 주는 일.

**걸리는 시간: 10분 내외 · 비용: 없음 · 개발 지식: 필요 없음**

---

## 왜 필요한가

지금 앱은 기록을 **선생님 기기의 브라우저 안에만** 저장합니다. 그래서

- 다른 선생님 휴대폰에서는 그 기록이 보이지 않습니다
- 브라우저 데이터를 지우면 사라집니다
- PC에서 표로 모아 보거나 출력할 수 없습니다

구글 시트에 함께 쌓으면 이 세 가지가 해결됩니다.
**기존 저장은 그대로 두고 시트에 한 벌 더 보내는 방식**이라, 인터넷이 끊겨도 앱은 평소처럼 동작합니다.

---

## 1단계 — 시트 만들기

1. [sheets.google.com](https://sheets.google.com) 접속 → **빈 스프레드시트**
2. 왼쪽 위 이름을 **`히든아카데미 기록`** 으로 바꿉니다

> 시트 안의 탭(수업기록·숙제기록·상담기록)은 **직접 만들지 않아도 됩니다.**
> 첫 기록이 들어올 때 스크립트가 제목줄과 함께 자동으로 만듭니다.

## 2단계 — 스크립트 붙여넣기

1. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭
2. 새 탭이 열리면 편집기에 있는 기본 코드(`function myFunction() {}`)를 **모두 지웁니다**
3. 이 폴더의 **[`Code.gs`](Code.gs)** 내용을 **전부 복사해 붙여넣습니다**
4. 맨 위 `SECRET` 줄을 고칩니다

```javascript
var SECRET = '여기에-직접-정한-비밀번호를-넣으세요';
```
↓ 아무 뜻 없는 긴 문자열로 바꿉니다 (예시를 그대로 쓰지 마세요)

```javascript
var SECRET = 'hidden-2026-kQ7xR2mZ9pLw';
```

5. 위쪽 **💾 저장** 버튼 클릭

## 3단계 — 배포 (인터넷에서 쓸 수 있게 켜기)

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(⚙) → **웹 앱** 선택
3. 아래처럼 맞춥니다

| 항목 | 고를 값 |
|---|---|
| 설명 | `학원 기록 수신` (아무거나) |
| 다음 사용자로 실행 | **나** |
| 액세스 권한이 있는 사용자 | **모든 사용자** |

> **"모든 사용자"가 맞습니다.** 앱이 로그인 없이 기록을 보내야 하기 때문입니다.
> 대신 2단계에서 정한 **비밀번호를 모르면 아무것도 쓸 수 없습니다.**

4. **배포** 클릭
5. **권한 승인** 창이 뜹니다
   - 계정 선택 → **"Google에서 확인하지 않은 앱입니다"** 화면이 나오면
   - 왼쪽 아래 **고급** → **(안전하지 않음)으로 이동** 클릭
   - **허용**

> 이 경고는 정상입니다. 원장님이 직접 만든 스크립트라서 구글이 아직 모른다는 뜻입니다.

6. **웹 앱 URL**을 복사합니다
   - `https://script.google.com/macros/s/` 로 시작하고 `/exec` 로 끝나는 긴 주소입니다.
   - **화면에 보이는 주소를 그대로 복사**해 주세요. 이 안내문에 적힌 예시를 붙여넣으면 연결되지 않습니다.

## 4단계 — 연결 확인

복사한 주소를 **브라우저 주소창에 붙여넣고 엔터**를 칩니다.

아래처럼 나오면 성공입니다.

```json
{"ok":true,"message":"연결되었습니다. 이 주소를 앱 설정에 넣으세요.",
 "data":{"sheets":["수업기록","숙제기록","상담기록"],"secret_set":true}}
```

| 나온 화면 | 뜻 | 할 일 |
|---|---|---|
| `"ok":true` | 정상 | 5단계로 |
| `"secret_set":false` | 비밀번호를 안 바꿈 | 2단계 4번 다시 |
| 로그인 화면 | 액세스 권한이 "모든 사용자"가 아님 | 3단계 3번 다시 |
| 404 / 오류 | 주소가 `/exec` 로 끝나는지 확인 | 6단계에서 다시 복사 |

## 5단계 — 앱에 연결하기

**웹 앱 주소**와 **비밀번호** 두 가지를 저에게 알려주시면 앱 설정에 넣는 화면까지 만들어 드립니다.

---

## 코드를 고쳤을 때 (중요)

`Code.gs` 를 수정하면 **저장만으로는 반영되지 않습니다.**
**배포 → 배포 관리 → 연필(✏️) → 버전: 새 버전 → 배포** 를 눌러야 합니다.
이때 주소는 그대로 유지됩니다.

---

## 알아두실 점

**주소와 비밀번호는 앱 안에 저장됩니다.**
앱을 쓰는 사람은 브라우저 개발자 도구로 이 값을 볼 수 있습니다.
학원 내부 선생님만 쓰는 도구라면 실무상 문제없지만, 원리는 알고 계시는 게 좋습니다.

**스크립트는 쓰기만 합니다.** 시트 내용을 읽어서 돌려주는 기능은 넣지 않았습니다.
주소가 새어 나가도 남의 학생 기록을 가져갈 수는 없습니다.

**같은 기록을 다시 보내면 줄이 늘지 않습니다.**
`record_id` 로 기존 줄을 찾아 고칩니다. 선생님이 기록을 수정하면 시트도 같이 바뀝니다.

**구글 무료 한도는 하루 2만 건**입니다. 학원 규모에서는 넘길 일이 없습니다.

## 시트에 쌓이는 열

### 수업기록

| 열 이름 | 내용 | 앱의 어느 값인가 |
|---|---|---|
| `saved_at` | 보낸 시각 | 자동 |
| `record_id` | 기록 고유번호 | `lesson.id` |
| `student_name` | 학생명 | `lesson.studentName` |
| `class_date` | 수업일 | `lesson.date` |
| `teacher` | 담당 교사 | `lesson.teacher` |
| `progress` | 진도 | `lesson.input.progress` |
| `understanding` | 이해도 | `lesson.input.understanding` |
| `understanding_note` | 이해도 메모 | `lesson.input.understandingNote` |
| `improve` | 보완 사항 | `lesson.input.improve` |
| `homework` | 숙제 | `lesson.input.homework` |
| `note` | 선생님 메모 | `lesson.input.memo` |

### 숙제기록 · 상담기록

`Code.gs` 의 `LAYOUT` 에 정의되어 있습니다. 필요 없으면 그 부분을 지워도 됩니다.
열을 빼고 싶으면 `columns` 배열에서 이름을 지우면 됩니다.
