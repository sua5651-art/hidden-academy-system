# 학원 운영 앱 — 수업 피드백 · 숙제 · 상담 · 내신

선생님이 **짧은 메모**만 입력하면 학부모님께 바로 보낼 수 있는
**피드백 문장**과 **숙제 안내 문장**을 자동으로 만들고,
**상담 기록**을 학생별로 쌓고, **중등 내신 준비 상태**를 학교별로 관리하는
학원 운영 도구입니다.

네 기능이 **학생 명단을 함께 쓰므로** 학생을 한 번만 등록하면 됩니다.

> 설치·서버·월 비용이 필요 없습니다. 휴대폰 브라우저에서 바로 씁니다.

---

## 1. 바로 써 보기

### 방법 A — 파일로 바로 열기 (가장 빠름)

`index.html` 파일을 브라우저에서 열면 끝입니다.

### 방법 B — 휴대폰에서 쓰기 (권장, GitHub Pages 무료 배포)

1. GitHub 저장소 → **Settings** → **Pages**
2. *Source* 를 **Deploy from a branch**, *Branch* 를 `main` / `(root)` 로 지정
3. 1~2분 뒤 나오는 주소를 휴대폰으로 접속
4. 브라우저 메뉴 → **홈 화면에 추가** → 앱처럼 실행됩니다

---

## 2. 화면 구성

아래 탭 5개로 움직입니다. 자주 쓰는 **수업 기록 · 숙제 배정 · 상담 기록**은
홈 화면 버튼으로 바로 갈 수 있습니다. (탭을 늘리지 않기 위한 선택입니다)

| 탭 | 하는 일 |
|---|---|
| 🏠 홈 | 오늘 요약 + **새 수업 기록 / 숙제 배정** 바로가기 |
| 👥 학생 | 학생 등록·수정, 학생별 기본 숙제 관리 |
| 📋 수업 | 수업 기록 목록 → 피드백 생성·확정 (작성 버튼 포함) |
| 📚 숙제 | 숙제 목록 → 배정·완료 체크·교사 확인 |
| 💬 상담 | 탭 대신 **홈 버튼**과 **학생 화면**에서 들어갑니다 |
| 📝 내신 | 탭 대신 홈의 **시험 대비 카드**와 학생 화면에서 들어갑니다 |
| ⚙️ 설정 | 말투, 교사 목록, AI 연결, 백업/복원 |

## 3. 사용 순서 (선생님용)

### 수업 피드백

```
① 학생 등록          👥 학생 탭 → ＋ 학생 추가
② 수업 기록 작성      🏠 홈 → ✏️ 새 수업 기록 → 7개 항목 입력 → 저장
                     (📋 수업 탭의 작성 버튼으로도 들어갈 수 있습니다)
③ 피드백 생성         🤖 피드백 생성 버튼 → 문장 자동 완성
④ 확인 후 전송        문장 수정 → ✅ 최종 확정 → 📋 복사 → 카톡·문자
```

### 상담 기록

```
① 상담 기록 작성      🏠 홈 → 💬 상담 기록
                     (👥 학생 탭 → 학생 선택 → ＋ 상담 기록 작성 도 가능)
② 9개 항목 입력       상담일·대상·유형·내용·요청사항·답변·후속조치·확인일
③ 요약 만들기         🤖 버튼 → 상담 내용이 3~5줄로 정리됨
④ 후속조치 관리       ✅ 완료 표시 → 홈 알림에서 사라짐
⑤ 과거 기록 조회      학생 화면 → 💬 상담 N건 (최신순 정렬)
```

### 중등 내신 관리

```
① 시험 정보 등록      🏠 홈 → 시험 대비 카드 → ＋ 시험 정보 등록
                     학교·학년·교과서·시험일·단원·문법·수행평가
                     → 입력하는 동안 "연결될 학생 N명"을 바로 알려 줍니다
② 준비 상태 체크      시험 상세 → 학생 선택
                     단원마다 [시작 전 / 진행중 / 완료] 두 줄 (준비 · 본문 암기)
③ 취약 문법 선택      시험에 등록한 문법 중에서 고릅니다
④ 오답 수 · 보강      숫자 입력 + 보강 필요 체크
⑤ 체크리스트 생성      📋 버튼 → 아직 남은 것만 뽑아 줍니다 → 복사
```

### 숙제 관리

```
① 기본 숙제 등록      👥 학생 탭 → 학생 선택 → 기본 숙제 저장 (한 번만)
② 숙제 배정          🏠 홈 → 📚 숙제 배정 → 학생 선택
                     (📚 숙제 탭의 배정 버튼으로도 들어갈 수 있습니다)
                     → 기본 숙제가 자동으로 채워짐
③ 오늘 내용 반영      기본 숙제 수정 + 오늘 추가 숙제 입력 → 저장
④ 완료 체크·교사확인   체크박스로 완료 표시 → ✅ 확인 완료로 표시
⑤ 학부모 안내        📝 문장 만들기 → 📋 복사 → 카톡·문자
```

### 입력 항목

| 항목 | 필수 | 설명 |
|---|:---:|---|
| 학생명 | ✅ | 등록된 학생 중 선택 |
| 수업 날짜 | ✅ | 기본값은 오늘 |
| 담당 교사 | ✅ | 목록 선택 또는 직접 입력 |
| 오늘 수업 진도 | ✅ | 피드백의 "오늘 학습 내용"이 됩니다 |
| 학습 상태·이해도 | ✅ | 5단계 버튼 중 하나 선택 |
| 이해도 메모 | | "학습 상태" 문단에 덧붙습니다 |
| 보완 필요 사항 | | 비우면 "보완 사항 없음"으로 안내 |
| 숙제 | | 비우면 "숙제 없음"으로 안내 |
| 선생님 메모 | | 비우면 "전달사항" 문단 자체가 생략 |

### 생성되는 피드백 (5단 구성)

```
[김민준 학생 수업 피드백]
2026년 9월 17일 (수) · 담당 김선생

■ 오늘 학습 내용
오늘은 아래 내용을 학습했습니다.
· 능률(김) 3과 본문 1~2문단 해석
· 관계대명사 which 정리

■ 학습 상태
오늘 수업 내용 중 일부는 추가 연습이 필요합니다.
which·that 구분을 두 번 틀림

■ 보완 내용
다음 수업에서 아래 부분을 보완하겠습니다.
· which와 that 구분 문제 10문항 추가 연습 필요

■ 숙제
· 워크북 p.42~45
· 단어 3과 1~40번 암기
가정에서도 확인 부탁드립니다.

■ 전달사항
다음 주 서해고 중간고사 범위 확인 부탁드립니다

- 히든 아카데미
```

### 문장 작성 6원칙

생성되는 모든 문장은 아래 6가지 규칙을 따릅니다.
**규칙 기반 생성과 AI 생성 모두 같은 규칙**을 적용합니다.

| # | 원칙 | 어떻게 지켜지는가 |
|:-:|---|---|
| 1 | **사실 중심** | 선생님이 입력한 사실만 서술. 추측·인상·전망은 쓰지 않음 |
| 2 | **과장 칭찬 금지** | "훌륭합니다·완벽합니다·탁월합니다" 등 금지. 감탄 부호(!)·이모지 금지 |
| 3 | **부정 단정 금지** | "못합니다·부족합니다" 대신 "아직 ~가 더 필요합니다" + **다음 학습 방향**을 함께 제시 |
| 4 | **짧은 문단** | 항목당 최대 3문장, 한 줄 60자 이내. 나열은 "· " 목록으로 분리 |
| 5 | **숙제 별도 명시** | 숙제는 숙제 항목에만, **한 줄에 하나씩**. 다른 내용과 섞지 않음 |
| 6 | **추가 금지** | 입력에 없는 점수·교재명·쪽수·태도 평가를 넣지 않음 |

> 원칙 3 적용 예: 이해도가 "많이 부족"이고 보완 입력이 비어 있어도,
> 문장이 단정으로 끝나지 않도록 **"다음 수업에서 해당 내용을 다시 점검하겠습니다."** 가 자동으로 붙습니다.

## 4. 숙제 관리 — 기본 숙제와 당일 숙제의 분리

요청하신 대로 **데이터 구조에서 완전히 분리**했습니다.

| 구분 | 어디에 저장되나 | 성격 |
|---|---|---|
| **기본 숙제** | 학생 정보 안 (`student.defaultHomework`) | 매번 반복되는 숙제. 한 번 등록하면 계속 재사용 |
| **오늘 추가 숙제** | 그날의 숙제 기록 안 (`homework.extra`) | 그 날짜에만 해당 |
| **그날 불러온 기본 숙제** | 그날의 숙제 기록 안 (`homework.base`) | 기본 숙제를 **복사해 온 사본** |

핵심은 세 번째입니다. 숙제를 배정하면 학생의 기본 숙제가 그날 기록으로
**복사**되어 들어옵니다. 그래서:

- 오늘 "워크북 p.42~45"를 "p.42~50"으로 고쳐도 → **학생의 기본 숙제는 그대로**
- 기본 숙제 자체를 바꾸려면 → 체크박스를 켜거나 학생 화면에서 저장
- 지난 기록을 열어 보면 → **그날 실제로 낸 숙제**가 그대로 남아 있음

> 이렇게 하지 않으면 기본 숙제를 한 번 고칠 때 **지난 기록까지 전부 바뀌어**
> "그날 무슨 숙제를 냈는지" 확인할 수 없게 됩니다.

### 숙제 항목

| 항목 | 설명 |
|---|---|
| 기본 숙제 | 학생별로 등록해 두고 자동으로 불러옴 |
| 오늘 추가 숙제 | 그날만 추가하는 숙제 |
| 제출 예정일 | 숙제 날짜보다 앞설 수 없음 |
| 완료 여부 | 항목마다 체크. 진행률이 막대로 표시됨 |
| 교사 확인 | 확인한 사람·시각·메모가 함께 기록됨 |

### 생성되는 숙제 안내 문장

```
[김민준 학생 숙제 안내]
2026년 9월 17일 (수) · 내신 A반 · 담당 김선생

■ 기본 숙제
· 워크북 p.42~50 (완료)
· 단어 3과 1~40번 암기

■ 오늘 추가 숙제
· 서술형 대비 문제 5번~8번

■ 제출 예정일
2026년 9월 19일 (금)까지

■ 진행 상황
전체 3개 중 1개 완료 (남은 항목 2개)

■ 교사 확인
담당 교사가 숙제를 확인했습니다.
단어 암기 상태 확인함

가정에서도 확인 부탁드립니다.

- 히든 아카데미
```

> 피드백과 같은 원칙을 씁니다. **선생님이 입력한 숙제만** 나오고,
> 완료 현황은 **체크한 개수를 사실 그대로** 적습니다.
> 비어 있는 항목(추가 숙제 없음, 교사 확인 전)은 **문단 자체가 생략**됩니다.

## 5. 중등 내신 관리 — 학교 공통과 학생별의 분리

요청하신 대로 **두 구조를 완전히 나눴습니다.**

| 구분 | 무엇이 들어가나 | 누구에게 적용되나 |
|---|---|---|
| **exam** (학교 공통) | 학교명·학년·교과서/출판사·시험일·시험범위(단원)·문법 범위·수행평가/서술형 | 그 학교·학년 학생 **전원** |
| **prep** (학생별) | 목표점수·단원별 준비 상태·본문 암기 상태·취약 문법·오답 수·보강 필요 여부 | 학생 **한 명** |

`prep` 은 `exam` 을 **가리키기만** 합니다. 그래서:

- 시험일이 하루 미뤄지면 → **학교 정보 한 줄만 고치면** 그 학교 학생 전원에게 반영
- 학생 한 명의 체크를 바꿔도 → **학교 공통 정보는 그대로**
- 시험범위에서 단원을 빼면 → 학생 기록의 그 단원 체크도 **자동으로 정리**

### 기능 1 — 한 번 등록하면 자동 연결

`학교명 + 학년`이 같은 학생이 자동으로 연결됩니다. 학생을 **나중에 등록해도** 조건만 맞으면
바로 목록에 나타납니다. (학년을 비우면 그 학교 전체)

> 학교·학년 표기가 학생 쪽과 다르면 연결이 안 되므로,
> 시험 정보를 입력하는 동안 **"이 조건에 맞는 학생 N명"** 을 실시간으로 알려 줍니다.

### 기능 2 — 단원별 준비 상태

단원마다 **두 줄**을 체크합니다.

```
Lesson 6                                    [미완료]
  단원 준비   [시작 전][진행중][완료]
  본문 암기   [시작 전][진행중][완료]
```

전체 항목 = **단원 수 × 2**. 진행률이 막대로 표시됩니다.

### 기능 3·4 — 남은 기간과 미완료 강조

- 시험일까지 남은 날이 **D-9** 처럼 배지로 표시됩니다 (7일 이내 빨강 · 14일 이내 노랑)
- 홈 화면 **시험 대비 카드**에 다가오는 시험과 `준비 완료 2/5명`이 보입니다
- 미완료 단원은 **왼쪽에 노란 띠**가 붙고 `미완료` 배지가 달립니다

### 기능 5 — 시험 전 최종 체크리스트

**아직 남은 것만** 뽑습니다. 끝낸 항목은 넣지 않습니다 — 그래야 시험 직전에 쓸모가 있습니다.

```
[김민준 학생 시험 대비 체크리스트]
정왕중 중3 2학기 중간고사
2026년 9월 26일 (토) · D-9
교과서 천재(이재영)
목표 점수 95점

준비 2/4 완료 (50%)

■ 아직 남은 단원 준비
· Lesson 6 (진행중)

■ 아직 남은 본문 암기
· Lesson 6 (시작 전)

■ 집중해야 할 문법
· 관계대명사 which/that
· 관계대명사 what 용법

■ 오답 정리
· 오답 12문항 — 시험 전 다시 풀어 보기

■ 보강
· 주말 보강 1회 — 관계대명사 집중

■ 수행평가 · 서술형
· 서술형 30% · 본문 요약 쓰기 수행평가
```

> 다 끝낸 학생은 남은 항목 문단이 아예 나오지 않고
> "표시된 준비 항목을 모두 끝냈습니다." 한 줄만 나옵니다.
> 체크리스트도 **선생님이 체크한 것과 입력한 것만** 쓰고, 생성 후 대조 검증합니다.

## 6. 상담 기록 — 원문과 요약의 분리

요청하신 대로 **상담 원문과 AI 요약을 별도 필드로** 저장합니다.

| 필드 | 내용 | 규칙 |
|---|---|---|
| `content` | 선생님이 적은 **상담 내용 원문** | 프로그램이 절대 고치지 않음 |
| `summary` | **3~5줄 요약** (본문·줄 목록·만든 방식·만든 시각) | 몇 번을 다시 만들어도 원문은 그대로 |

> 원문이 항상 남아 있어야 나중에 **"실제로 무슨 이야기가 오갔는지"** 확인할 수 있습니다.
> 요약만 남기면 분쟁이 생겼을 때 근거가 사라집니다.

### 입력 항목 (9개)

학생명 · 상담일 · 상담 대상 · 상담 유형 · 상담 내용 · 학부모 요청사항 ·
학원 답변 · 후속조치 · 다음 확인일

- **상담 대상**: 학부모 / 학생 / 학부모+학생 / 기타
- **상담 유형**: 정기 상담 / 성적 상담 / 진학·진로 / 학습 태도 / 출결 / 학부모 요청 / 불만·건의 / 기타

### 요약은 어떻게 만들어지나

기본값은 **발췌 방식**입니다. 원문에서 중요한 문장을 **골라낼 뿐 새로 쓰지 않으므로**
없는 내용이 들어갈 수 없습니다. (성적·시험·숙제·태도·출결·진학·요청 같은 말이 들어간 문장,
숫자가 있는 문장, 첫 문장에 가중치를 둡니다.)

```
· [성적 상담] 학부모 상담
· 2학기 중간고사 영어 성적이 3등급으로 한 등급 떨어졌다고 걱정하셨습니다.
· 학부모 요청: 단어 시험을 매주 봐 주셨으면 합니다
· 학원 답변: 다음 주부터 매주 금요일 단어 시험을 진행하기로 안내드렸습니다
· 후속조치: 2주 뒤 단어 시험 결과 정리해서 다시 연락
```

학부모 요청사항과 학원 답변은 **반드시 각각 한 줄**로 남습니다.
AI를 켜면 문장을 다듬어 주고, 생성 후 **원문과 대조 검증**합니다
(없는 점수·교재명은 🔴, 5줄을 넘으면 🟡).

> 원문이 짧으면 3줄이 안 될 수도 있습니다. **억지로 채우면 그게 지어내기**이기 때문입니다.

### 후속조치와 다음 확인일

| 기능 | 동작 |
|---|---|
| 후속조치 필요 표시 | 목록에 `후속조치 필요` 배지, "필요한 것만 보기" 필터 |
| 다음 확인일 알림 | 확인일 **3일 이내이거나 지난** 상담을 홈 화면에 D-day로 표시 |
| 완료 처리 | 후속조치를 끝내면 알림에서 자동으로 빠짐 |

### 수정 이력

기록을 고치면 **언제 · 무엇을 고쳤는지**가 남습니다.

```
최초 작성    2026. 9. 17. 오후 2:10
마지막 수정  2026. 9. 19. 오전 11:04

2026. 9. 19. 오전 11:04   학원 답변, 다음 확인일 수정
2026. 9. 18. 오후 5:22    상담 내용 수정
```

바뀐 내용이 없으면 이력을 남기지 않습니다.

## 7. 규칙이 실제로 지켜지게 만드는 3중 안전장치

규칙을 "부탁"만 하면 AI는 어길 수 있습니다. 세 겹으로 강제합니다.

**① 기본값이 '규칙 기반' — 구조적으로 어길 수 없음**

기본 설정은 AI가 아니라 **규칙 기반**입니다.
프로그램은 연결어만 붙이고 **내용은 100% 선생님이 쓴 글자 그대로** 들어가므로,
없는 사실이 들어갈 수도, 과장 칭찬이 생길 수도 없습니다.

**② AI 사용 시 6원칙을 지시문으로 강제**

금지 표현을 하나하나 나열해 전달하고, `temperature 0` 으로 호출합니다.

**③ 생성 후 자동 검사 — 어기면 화면에 표시**

| 검사 항목 | 표시 | 동작 |
|---|---|---|
| 입력에 없는 **숫자·영어** | 🔴 빨간 경고 | 확정 전 **재확인 창**으로 한 번 더 막음 |
| **과장 칭찬 / 부정 단정** 표현 | 🟡 표현을 다듬어 주세요 | 해당 표현을 짚어서 표시 |
| 입력에 없는 **한글 표현** | 🟡 입력에서 찾을 수 없는 표현 | 목록으로 표시 |

실제 동작 예 (테스트로 검증됨):

```
🔴 입력에 없는 숫자 "95"이(가) 문장에 있습니다.
🔴 입력에 없는 영어 표현 "Reading"이(가) 문장에 있습니다.
🟡 "훌륭" 은(는) 과장된 칭찬 표현입니다. 사실 위주로 바꿔 주세요.
🟡 "이해하지 못" 은(는) 부정적으로 단정하는 표현입니다. 다음 학습 방향과 함께 표현해 주세요.
```

> 선생님이 **직접 그렇게 입력한 경우에는 잡지 않습니다.**
> 예를 들어 선생님이 메모에 "아직 부족합니다"라고 썼다면 경고하지 않습니다.

## 8. 데이터 보호 규칙

요청하신 **"기존 데이터를 임의로 삭제하지 않는다"** 를 코드 수준에서 지킵니다.

| 규칙 | 구현 |
|---|---|
| 기록 삭제 불가 | 수업·숙제·상담·내신 기록 모두 삭제 기능이 없음. **보관(숨기기)** 만 가능하며 데이터는 남음 |
| 수정 이력 보존 | 문장이 바뀔 때마다 이전 내용을 `history` 에 누적 (화면에서 확인 가능) |
| 확정 후 보호 | 확정된 기록은 **읽기 전용**. "수정 잠금 해제"를 눌러야 편집 가능 |
| 저장 실패 대비 | 저장 실패 시 자동으로 이전 상태 복구 + 백업 키에 직전 정상본 보관 |
| 가져오기는 병합 | 덮어쓰기가 아니라 **없는 것만 추가**. 기존 데이터가 사라지지 않음 |
| 예전 백업 호환 | 숙제·상담·내신 기능 이전에 만든 백업 파일도 그대로 읽힘 (빠진 항목은 자동 생성) |
| 상담 원문 보호 | 요약을 몇 번을 다시 만들어도 상담 원문은 바뀌지 않음 |
| 시험·학생 기록 분리 | 시험 정보를 고쳐도 학생 준비 기록은 사라지지 않음 |
| 초기화는 2단계 확인 | 실수로 눌러도 두 번 확인해야 실행됨 |

> ⚠️ 데이터는 **그 기기의 브라우저 안에만** 저장됩니다.
> 설정 화면에서 **주 1회 백업 파일을 내려받아** 두세요.
> 기기를 바꾸면 백업 파일을 가져오기로 옮기면 됩니다.
