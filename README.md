# 수업 피드백 자동 생성 앱

선생님이 **짧은 수업 메모**만 입력하면, 학부모님께 바로 보낼 수 있는
**피드백 문장**을 자동으로 만들어 주는 학원 운영 도구입니다.

> 설치·서버·월 비용이 필요 없습니다. 휴대폰 브라우저에서 바로 씁니다.

---

## 1. 바로 써 보기

### 방법 A — 파일로 바로 열기 (가장 빠름)

`index.html` 파일을 브라우저에서 열면 끝입니다.

### 방법 B — 휴대폰에서 쓰기 (권장, GitHub Pages 무료 배포)

1. GitHub 저장소 → **Settings** → **Pages**
2. *Source* 를 **Deploy from a branch**, *Branch* 를 `main` / `(root)` 로 지정
3. 1~2분 뒤 나오는 주소를 휴대폰으로 접속
4. 브라우저 메뉴 → **홈 화면에 추가** → 앱처럼 실행됩니다

---

## 2. 사용 순서 (선생님용 4단계)

```
① 학생 등록          👥 학생 탭 → ＋ 학생 추가
② 수업 기록 작성      ✏️ 기록 탭 → 7개 항목 입력 → 저장
③ 피드백 생성         🤖 피드백 생성 버튼 → 문장 자동 완성
④ 확인 후 전송        문장 수정 → ✅ 최종 확정 → 📋 복사 → 카톡·문자
```

### 입력 항목

| 항목 | 필수 | 설명 |
|---|:---:|---|
| 학생명 | ✅ | 등록된 학생 중 선택 |
| 수업 날짜 | ✅ | 기본값은 오늘 |
| 담당 교사 | ✅ | 목록 선택 또는 직접 입력 |
| 오늘 수업 진도 | ✅ | 피드백의 "오늘 학습 내용"이 됩니다 |
| 학습 상태·이해도 | ✅ | 5단계 버튼 중 하나 선택 |
| 이해도 메모 | | "학습 상태" 문단에 덧붙습니다 |
| 보완 필요 사항 | | 비우면 "보완 사항 없음"으로 안내 |
| 숙제 | | 비우면 "숙제 없음"으로 안내 |
| 선생님 메모 | | 비우면 "전달사항" 문단 자체가 생략 |

### 생성되는 피드백 (5단 구성)

```
[김민준 학생 수업 피드백]
2026년 9월 17일 (수) · 담당 김선생

■ 오늘 학습 내용
오늘은 아래 내용을 학습했습니다.
· 능률(김) 3과 본문 1~2문단 해석
· 관계대명사 which 정리

■ 학습 상태
오늘 수업 내용 중 일부는 추가 연습이 필요합니다.
which·that 구분을 두 번 틀림

■ 보완 내용
다음 수업에서 아래 부분을 보완하겠습니다.
· which와 that 구분 문제 10문항 추가 연습 필요

■ 숙제
· 워크북 p.42~45
· 단어 3과 1~40번 암기
가정에서도 확인 부탁드립니다.

■ 전달사항
다음 주 서해고 중간고사 범위 확인 부탁드립니다

- 히든 아카데미
```

### 문장 작성 6원칙

생성되는 모든 문장은 아래 6가지 규칙을 따릅니다.
**규칙 기반 생성과 AI 생성 모두 같은 규칙**을 적용합니다.

| # | 원칙 | 어떻게 지켜지는가 |
|:-:|---|---|
| 1 | **사실 중심** | 선생님이 입력한 사실만 서술. 추측·인상·전망은 쓰지 않음 |
| 2 | **과장 칭찬 금지** | "훌륭합니다·완벽합니다·탁월합니다" 등 금지. 감탄 부호(!)·이모지 금지 |
| 3 | **부정 단정 금지** | "못합니다·부족합니다" 대신 "아직 ~가 더 필요합니다" + **다음 학습 방향**을 함께 제시 |
| 4 | **짧은 문단** | 항목당 최대 3문장, 한 줄 60자 이내. 나열은 "· " 목록으로 분리 |
| 5 | **숙제 별도 명시** | 숙제는 숙제 항목에만, **한 줄에 하나씩**. 다른 내용과 섞지 않음 |
| 6 | **추가 금지** | 입력에 없는 점수·교재명·쪽수·태도 평가를 넣지 않음 |

> 원칙 3 적용 예: 이해도가 "많이 부족"이고 보완 입력이 비어 있어도,
> 문장이 단정으로 끝나지 않도록 **"다음 수업에서 해당 내용을 다시 점검하겠습니다."** 가 자동으로 붙습니다.

---

## 3. 규칙이 실제로 지켜지게 만드는 3중 안전장치

규칙을 "부탁"만 하면 AI는 어길 수 있습니다. 세 겹으로 강제합니다.

**① 기본값이 '규칙 기반' — 구조적으로 어길 수 없음**

기본 설정은 AI가 아니라 **규칙 기반**입니다.
프로그램은 연결어만 붙이고 **내용은 100% 선생님이 쓴 글자 그대로** 들어가므로,
없는 사실이 들어갈 수도, 과장 칭찬이 생길 수도 없습니다.

**② AI 사용 시 6원칙을 지시문으로 강제**

금지 표현을 하나하나 나열해 전달하고, `temperature 0` 으로 호출합니다.

**③ 생성 후 자동 검사 — 어기면 화면에 표시**

| 검사 항목 | 표시 | 동작 |
|---|---|---|
| 입력에 없는 **숫자·영어** | 🔴 빨간 경고 | 확정 전 **재확인 창**으로 한 번 더 막음 |
| **과장 칭찬 / 부정 단정** 표현 | 🟡 표현을 다듬어 주세요 | 해당 표현을 짚어서 표시 |
| 입력에 없는 **한글 표현** | 🟡 입력에서 찾을 수 없는 표현 | 목록으로 표시 |

실제 동작 예 (테스트로 검증됨):

```
🔴 입력에 없는 숫자 "95"이(가) 문장에 있습니다.
🔴 입력에 없는 영어 표현 "Reading"이(가) 문장에 있습니다.
🟡 "훌륭" 은(는) 과장된 칭찬 표현입니다. 사실 위주로 바꿔 주세요.
🟡 "이해하지 못" 은(는) 부정적으로 단정하는 표현입니다. 다음 학습 방향과 함께 표현해 주세요.
```

> 선생님이 **직접 그렇게 입력한 경우에는 잡지 않습니다.**
> 예를 들어 선생님이 메모에 "아직 부족합니다"라고 썼다면 경고하지 않습니다.

## 4. 데이터 보호 규칙

요청하신 **"기존 데이터를 임의로 삭제하지 않는다"** 를 코드 수준에서 지킵니다.

| 규칙 | 구현 |
|---|---|
| 기록 삭제 불가 | 삭제 기능 자체가 없음. **보관(숨기기)** 만 가능하며 데이터는 남음 |
| 수정 이력 보존 | 문장이 바뀔 때마다 이전 내용을 `history` 에 누적 (화면에서 확인 가능) |
| 확정 후 보호 | 확정된 기록은 **읽기 전용**. "수정 잠금 해제"를 눌러야 편집 가능 |
| 저장 실패 대비 | 저장 실패 시 자동으로 이전 상태 복구 + 백업 키에 직전 정상본 보관 |
| 가져오기는 병합 | 덮어쓰기가 아니라 **없는 것만 추가**. 기존 데이터가 사라지지 않음 |
| 초기화는 2단계 확인 | 실수로 눌러도 두 번 확인해야 실행됨 |

> ⚠️ 데이터는 **그 기기의 브라우저 안에만** 저장됩니다.
> 설정 화면에서 **주 1회 백업 파일을 내려받아** 두세요.
> 기기를 바꾸면 백업 파일을 가져오기로 옮기면 됩니다.

## 5. AI 연결 (선택 사항)

기본은 꺼져 있습니다. 설정 화면에서 켤 수 있습니다.

| 방식 | 설명 | 안전도 |
|---|---|---|
| **프록시 주소** | 학원 서버가 API 키를 보관하고 대신 호출 | 🟢 권장 |
| **API 키 직접 입력** | 선생님 기기에 키를 저장 | 🟡 개인 기기만 |

> 여러 선생님이 함께 쓰는 공용 PC에는 **API 키를 직접 넣지 마세요.**
> 그 기기를 쓰는 사람이 볼 수 있습니다. 프록시 방식을 사용하세요.

## 6. 개발자용

### 파일 구조

```
├── index.html               화면 뼈대
├── manifest.webmanifest     홈 화면 추가(PWA) 설정
├── assets/
│   ├── css/style.css        디자인 (모바일 우선 · 다크 모드 지원)
│   └── js/
│       ├── store.js         데이터 저장·불러오기·백업 (localStorage)
│       ├── feedback.js      문장 생성 + 사실 대조 검증
│       ├── ai.js            Claude API 연결 (선택)
│       └── app.js           화면 동작 · 라우팅
├── tests/                   테스트
└── docs/DESIGN.md           화면 · 데이터 구조 설계서
```

### 테스트 실행

```bash
bash tests/run.sh
```

- `tests/logic.test.js` — 저장·생성·6원칙 검증 로직 61건 (node 만 있으면 실행)
- `tests/ui.test.js` — 실제 브라우저에서 전체 흐름 (playwright 필요)
- `tests/ai-guard.test.js` — 지어낸 내용·과장 칭찬·부정 단정을 잡아내는지 (playwright 필요)

빌드 도구·의존성 설치가 필요 없습니다. 파일을 그대로 열면 동작합니다.

자세한 화면·데이터 구조 설명은 **[docs/DESIGN.md](docs/DESIGN.md)** 를 참고하세요.
